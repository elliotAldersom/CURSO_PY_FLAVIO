# Categoría 04: Ordenamiento e Índices

Métodos para clasificar datos, manipular etiquetas y calcular rankings estadísticos.

| Método / Técnica | Tipo | Descripción | Enlace |
| :--- | :--- | :--- | :--- |
| `sort_values` | Método | Ordenamiento físico multicriterio por valores de columnas. | [sort_values.md](sort_values.md) |
| `reset_index` | Método | Restablece el índice a enteros continuos `0..n-1` o transforma índices a columnas. | [reset_index.md](reset_index.md) |
| `set_index` | Método | Promueve columnas del DataFrame a nuevo índice de filas. | [set_index.md](set_index.md) |
| `nlargest` | Método | Extracción optimizada por montículo de los $N$ mayores registros numéricos. | [nlargest.md](nlargest.md) |
| `nsmallest` | Método | Extracción optimizada por montículo de los $N$ menores registros numéricos. | [nsmallest.md](nsmallest.md) |
| `idxmax` | Método | Etiqueta del índice correspondiente al valor máximo. | [idxmax.md](idxmax.md) |
| `idxmin` | Método | Etiqueta del índice correspondiente al valor mínimo. | [idxmin.md](idxmin.md) |
| `rank` | Método | Asignación de rangos numéricos con control formal de empates (`min`, `dense`). | [rank.md](rank.md) |
