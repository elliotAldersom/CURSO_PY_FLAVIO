# Categoría 09: Combinación y Reestructuración

Herramientas para unir tablas relacionales, ensamblar lotes de datos y remodelar formatos entre ancho y largo.

| Método / Función | Tipo | Descripción | Enlace |
| :--- | :--- | :--- | :--- |
| `merge` | Función / Método | Uniones relacionales basadas en claves compartidas (`inner`, `left`, `outer`). | [merge.md](merge.md) |
| `concat` | Función | Ensamblado y apilamiento por ejes (filas o columnas). | [concat.md](concat.md) |
| `melt` | Método | Transformación de formato ancho (*wide*) a formato largo (*tidy*). | [melt.md](melt.md) |
