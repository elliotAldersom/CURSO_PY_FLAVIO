# Categoría 03: Selección y Filtrado

Técnicas e indexadores vectorizados para consultar, segmentar y extraer subconjuntos de datos tabulares.

| Método / Técnica | Tipo | Descripción | Enlace |
| :--- | :--- | :--- | :--- |
| `filtrado_booleano` | Técnica | Segmentación con operadores bitwise `&`, `|` y `~` en memoria vectorizada. | [filtrado_booleano.md](filtrado_booleano.md) |
| `loc` | Indexador | Acceso y asignación segura basada en etiquetas de filas y columnas. | [loc.md](loc.md) |
| `iloc` | Indexador | Acceso matricial basado estrictamente en posiciones enteras. | [iloc.md](iloc.md) |
| `query` | Método | Filtrado declarativo de alta legibilidad mediante strings y variables locales. | [query.md](query.md) |
| `isin` | Método | Evaluación vectorizada de pertenencia a listas o conjuntos de valores. | [isin.md](isin.md) |
| `between` | Método | Evaluación de intervalos numéricos o temporales continuos con control de extremos. | [between.md](between.md) |
| `str.contains` | Método | Búsqueda de subcadenas y patrones Regex en columnas de texto. | [str_contains.md](str_contains.md) |
