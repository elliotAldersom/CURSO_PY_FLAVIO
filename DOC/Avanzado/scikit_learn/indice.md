# Biblioteca Scikit-learn: Fichas Técnicas por Método y Componente

Scikit-learn es la biblioteca canónica de Machine Learning clásico y preprocesamiento en Python construida sobre la arquitectura de contratos `fit`, `transform` y `predict`.

## Estructura Modular

| Categoría | Descripción | Índice |
|---|---|---|
| **01. Preprocesamiento** | Estandarización numérica, codificación One-Hot e imputación de nulos | [01_preprocesamiento](01_preprocesamiento/indice.md) |
| **02. Partición y Selección** | Validación cruzada, partición estratificada y búsqueda de grilla | [02_particion_seleccion](02_particion_seleccion/indice.md) |
| **03. Estimadores Clásicos** | Regresión lineal y logística, árboles CART, Random Forest y K-Means | [03_estimadores_clasicos](03_estimadores_clasicos/indice.md) |
| **04. Métricas de Evaluación** | Matriz de confusión, reporte de clasificación F1 y error cuadrático medio | [04_metricas_evaluacion](04_metricas_evaluacion/indice.md) |
| **05. Pipelines** | Composición atómica contra fugas de datos y transformadores heterogéneos | [05_pipelines](05_pipelines/indice.md) |
