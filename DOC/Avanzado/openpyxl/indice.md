# Biblioteca OpenPyXL: Fichas Técnicas por Método y Componente

OpenPyXL es la biblioteca estándar en el ecosistema Python para manipulación programática integral de hojas de cálculo Microsoft Excel (formatos `.xlsx` y `.xlsm`).
